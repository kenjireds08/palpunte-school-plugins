# 実際に踏んだ失敗（症状から直し方を引く）

どれも対策は本文と道具に入れてある。「→」の先が正本。

## キー・安全

| 起きたこと | 原因 | 防いでいる所 |
|---|---|---|
| API キーが会話の記録に出て、作り直しになった | プロセスの一覧を `pgrep -fl` で見た（Mac では `pgrep -fl`・`ps e`・`ps eww` が環境変数ごと表示する） | プロセスの確認は `pgrep -f` だけ → `SKILL.md`「守ること」 |
| 存在の確認のつもりの `echo "${KEY:-未設定}"` がキーを表示した | `:-` は設定されていれば値を出す | キーの有無は `deps.mjs` で見る（値を出さない）→ `setup.md` |
| キーをチャット欄に貼ってしまう | 保存の手順が分からない | `save-key.ts` を受講生がターミナルで実行（画面に出ない）→ `setup.md`「鍵を保存する」 |
| 撮影のスクリプトにログインのパスワードが書かれたまま Git に入った | ログインの処理をスクリプトに書いた | `record.mjs --login` で受講生が自分でログイン → `capture.md`「ログインが要る画面」 |

## 台本・声

| 起きたこと | 原因 | 防いでいる所 |
|---|---|---|
| 動画に「24 時間いつでも予約」と出た（本当はキャンセル期限の 24 時間） | 資料の数字だけ拾った | 事実確認表に「何の数字か」まで書く → `script-and-voice.md` |
| 資料にある「お知らせメール」が実装に無かった | 資料を信じた | コードで確かめた機能だけ → `script-and-voice.md`「事実確認表」 |
| 「かみのタイムカード」が「神」の高さで読まれた | 同じ音の言葉をひらがなで渡した | 漢字で書く → `script-and-voice.md`「読み」 |
| 社名が 1 音違いで読まれ、作り直した | 読みを確かめなかった | 読みをかなで書き、受講生が 1 回聞く → `script-and-voice.md` |
| 同じ原稿でも、作るたびに読みが揺れた | 生成のゆらぎ | 1 本ごとに書き起こして比べる → `script-and-voice.md`「読み間違いの確認」 |
| ナレーションが見込みより短く、映像が余った | 見込みの字/秒と実際がずれた | 最初の 1 本で字/秒を測って台本を引き直す → `script-and-voice.md`「長さを測る」 |
| ElevenLabs の無料プランで Yuma Uchida が使えず止まった（Windows の実機・終了コード 6） | Voice Library の声は無料プランの API で使えない | 声は初回に 2 択で選ぶ（既定は Gemini）。止まったら「Starter にする／Gemini に切り替える」の 2 択 → `script-and-voice.md`「声を選ぶ」「ElevenLabs の無料プランで止まったとき」 |
| 無料プランの公式の声（George など）に替えたら、英語なまりの日本語になった | 公式の声は英語の話者の声 | 公式の声へは逃がさない（案内から外した） |
| Gemini の 1 日の上限の 429 で、翌日を指す Retry-After をそのまま待ちそうになった | 上限の 429 の待ち時間は当てにならない | `gemini-tts.ts` は 1 日の上限では待たずに止まり、2 択を出す → `setup.md`「Gemini（声）」 |

## 写真

| 起きたこと | 原因 | 防いでいる所 |
|---|---|---|
| 冒頭がいつも「紙片が散らばる絵」で、ワンパターンと言われた | 困りごとを物で表した | 困っている生活の場面の写真を数枚つなぐ → `images.md` |
| スマホを見ている人物の写真で、画面がカメラ側を向いていた | プロンプトに画面の向きを書かなかった | 「画面は本人の方・こちらは背面」を書き、検品で見る → `images.md` |
| 人物の性別を勝手に変えて、差し戻された | 「本人と間違われる」と気を回した | 性別・年代は台本どおり、迷ったら聞く → `images.md` |
| 最後にアプリの代わりの四角いアイコンを置いたら「ダサい」と言われた | 汎用のアイコンで締めた | 名前の文字で締める → `images.md` |

## 録画

| 起きたこと | 原因 | 防いでいる所 |
|---|---|---|
| 開発者本人の実名がダミーの会員に入っていた | 開発中に自分の名前で登録していた | 撮る前に画面に出る名前を書き出す → `capture.md`「撮る前に」 |
| 撮影で作った予約が残り、確認メールが届いた | 書き込みを止めていなかった | `record.mjs` は書き込みを全部止める。通すときは受講生の OK と後片付け → `capture.md`「書き込みが要る場面」 |
| 画面に元から「自動で 5 か所」と出ていて、ナレーションと食い違った | 画面の固定の文字を見ていなかった | 撮る前に画面の文字と台本を比べる → `capture.md` |
| 名前の置き換えでアプリの表の列が「—」になった | `<script>` の中まで書き換えた | 置き換えは画面の文字だけ（`record.mjs` が守る） |
| 録画の下に灰色の帯が出て、画面が縮んで欠けた | パソコンの Chrome（155）を画面なしで録画に使った | `record.mjs` は書き出し用のブラウザか、Chrome の窓ありで撮る → `capture.md` |
| 録画が「Video rendering requires ffmpeg binary」で止まった | Playwright の録画は、パソコンの ffmpeg ではなく Playwright 専用の ffmpeg を使う | `templates/package.json` の postinstall で入れる・`deps.mjs --dir` が確かめる |
| 録画の 5 秒ごとに 1 コマだけ大きくぼけた | Playwright の録画の性質（128 コマごと） | `record.mjs` が変換のときにそのコマを落とす |
| 書き出しのブラウザをダウンロードできなかった | ネットワークの制限 | パソコンの Chrome を使う（`HYPERFRAMES_BROWSER_PATH`）→ `compose.md`「書き出し」 |

## 組み立て・サムネイル

| 起きたこと | 原因 | 防いでいる所 |
|---|---|---|
| 声と HTML の場面の長さが食い違った | 長さの基準が 2 つあった | `effectiveSeconds` だけを基準にし、`showcase-check.ts timing` で突き合わせ → `compose.md` |
| サムネイルで PC が右端で切れ、スマホが画面の中身に重なった | 位置を目分量で決めた | 位置は型で固定・`render.ts` の配置の検査 → `compose.md`「サムネイル」 |
| 26MB の mp4 がアプリのプレビューで再生できなかった | 書き出しそのままの大きさ | 軽量版を作る → `compose.md`「書き出し」 |
| 日本語の文字が豆腐（□）になった | フォントの読み込み漏れ | `#glyph-warm` に全部の文字＋`gen-fonts.ts`。`render.ts` は別の書体に落ちたら止まる |
