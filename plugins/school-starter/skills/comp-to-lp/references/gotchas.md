# 困ったとき（comp-to-lp・受講生版）

SKILL.md の Gotchas の詳しい版。症状 → 原因 → 対処の順。

## 準備（STEP 0）

### `node: bad option: --env-file`
**原因:** Node が 20.6 より古い。
**対処:** 「Node.js を LTS 版に更新する手順を、このパソコンの OS に合わせて教えてください」と頼んで更新し、Claude のアプリを完全に終了して開き直す。

### 「Playwright（Node 版）が見つかりません」
**原因:** image-studio に playwright が入っていない。
**対処:** image-studio に package.json が無ければ、先に `npm init -y`。そのあと `npm i -D playwright@1.61.1`、次に `npx playwright install chromium`（1 つずつ別々に実行する）。

### playwright を入れたのに「作業フォルダに入っていません」と出る／ホームに package.json ができた
**原因:** image-studio に package.json が無いまま `npm i` を実行したので、上のフォルダ（ホームなど）の package.json に入った。
**対処:** image-studio で `npm init -y` → `npm i -D playwright@1.61.1` をやり直す。ホームにできた package.json と node_modules は、自分で作ったものでなければ講師に確かめてから消す。

### `Executable doesn't exist at .../chromium-XXXX`
**原因:** ブラウザ本体（chromium）が入っていない、または版が合っていない。
**対処:** `npx playwright install chromium` をもう一度。だめなら `npx playwright install --force chromium`。それでもだめなら、その人だけ画像の生成までにする。

### deps.mjs の「作業フォルダ」が NG
**原因:** Code タブで image-studio 以外のフォルダを開いている。
**対処:** 「Code タブで選んだフォルダが image-studio ではありません。作業フォルダを image-studio に選び直して、もう一度送ってください」と伝える。

### `.env.probe` が読めてしまった
**原因:** 鍵を守る設定（deny）が効いていない。
**対処:** 鍵を使う工程に進まない。講師に知らせる。

## 画像（STEP 2〜3）

### 「上限を超える見積もりです」
**原因:** 台帳の累計 ＋ 今回の見積もりが上限（最大 300 円）を超える。
**対処:** 枚数を減らす（アイコンを減らす・似た写真をまとめる）。上限は 300 円より上げられない。

### 「状態不明: <name>」
**原因:** 送ったあとで止まった（アプリを閉じた・通信が切れた）。課金されたか道具には分からない。
**対処:** 自動では作り直さない。OpenAI の Usage 画面で止めた時刻に課金があるか確かめ、無ければ `--only <name>` で作り直す。

### 「別の gen.mjs が同じ台帳を使っています」
**原因:** gen.mjs が 2 つ同時に動いている（または前回の gen.mjs がまだ終わっていない）。
**対処:** 先の 1 つが終わるのを待ってからもう一度実行する。gen.mjs は同時に 1 つだけ起動する（古いロックの片付けは 2 つを同時に起動した場合を考えていないため、同時に 2 回起動しない）。

### 「〜の中だけを指定できます」「名前が .env で始まる…」
**原因:** jobs.json や設定の書き出し先が `lp/` の外（`../`・絶対パス・外を指すリンク）か、鍵のファイルと同じ `.env` で始まる名前になっている。
**対処:** `assets/img/hero-bg.jpg` のように `lp/` の中の相対パスに直す。

### 「429: 並列数を ... に下げます」
**原因:** OpenAI の 1 分あたりの上限に当たった。画像 API の返事には上限が書いていないことが多く、道具はそのとき 2 枚ずつで始めるので、1 分 5 枚の枠の人はここで 1 枚ずつに下がる。
**対処:** 何もしない。道具が待ってから 1 枚ずつで自動で続ける。同じ素材で 2 回続くと err になり、作り直しの回で作られる。

### 「止めました: ... 残高（Billing）か鍵を確認してください」
**原因:** 残高不足（insufficient_quota）・鍵が無効（401）・本人確認の反映待ち（403）・エラーが 3 回続いた。
**対処:** 文言を受講生に伝えて止まる。残高を足す・鍵を作り直すのは受講生。直したら一括と同じコマンドで続きから作れる。

### 透過した画像のふちが汚い・白く残る
**原因:** 白地に灰色の影が出ている。
**対処:** プロンプトに `no shadow, no gradient, no gray` が入っているか確かめ、直す点としてそれを足して作り直す。

### 透過で「白地に黒の画像ではないようです」
**原因:** 写真なのに透過の対象（name が `icon-` などで始まる、kind が icon）になっている。
**対処:** jobs.json の kind を photo にする。

## HTML（STEP 3〜4）

### 画像が表示されない（mask-image を使ったとき）
**原因:** `mask-image: url(...)` はファイルを直接開くと読み込みを拒否される。
**対処:** 色ごとに透過 PNG を書き出す（`final` に色違いを並べる）。グラデーションの mask-image は動く。

### 文字の幅が合わない
**原因:** Web フォントの読み込み前に測った・指定した太さがフォントの URL に入っていない。
**対処:** 道具はフォントの読み込みを待っている。それでも合わなければ comp.config.json の `waitMs` を増やす。Google Fonts の URL に使う太さ（`wght@500;700` など）を入れる。

### 下のセクションがずっと合わない
**原因:** 上のセクションの高さがずれている。
**対処:** measure.mjs の top を上から順に合わせる。

### 比較画像の 3 段目が真っ白・真っ黒
**原因:** カンプと実装の高さが大きく違う。
**対処:** shot.mjs の最初の行の「差 ±Npx」を見て、まずセクションの高さを合わせる。

### ASSETS.md を作ろうとして止められた
**原因:** `.md` は `docs/` の下にしか作れない決まり。
**対処:** `lp/docs/ASSETS.md` に作る。止められたら、別の場所や別の方法で書かず、理由をそのまま伝える。
