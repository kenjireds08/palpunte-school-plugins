# school-starter プラグイン 変更履歴

最新が上。`/school-starter:setup` の更新時メッセージは、このファイルから
「前回入れていたバージョンより新しい節」を読み出して表示する。

各バージョンの見出しは `## vX.Y.Z — YYYY-MM-DD` 形式で固定（setup が機械的に拾うため崩さないこと）。
直近バージョンは詳細 bullet、それ以前は1行要約。元データは Notion「更新履歴」。
