# school-starter プラグイン 変更履歴

最新が上。`/school-starter:setup` の更新時メッセージは、このファイルから
「前回入れていたバージョンより新しい節」を読み出して表示する。

各バージョンの見出しは `## vX.Y.Z — YYYY-MM-DD` 形式で固定（setup が機械的に拾うため崩さないこと）。
それ以前の詳細な履歴は Notion「更新履歴」または `git log` を参照。

---

## v1.24.7 — 2026-06-16
- 更新時メッセージに「今回の更新で変わったこと」を**自動表示**する仕組みを追加。setup が本 changelog を読み出し、受講生が前回入れていたバージョンより新しい節をその場に表示する
- プラグイン内に `references/plugin-changelog.md` を新設。受講生に配布されないリポジトリルートの `docs/plugin-changelog.md` への参照（デッドリンク）を解消

## v1.24.6 — 2026-06-16
- `/school-starter:setup` を初回／更新で出し分けるようにした。更新・再実行時は初回専用の環境構築フル案内（Homebrew / Codex CLI / Node.js / 再起動 / sandbox 参考）を表示せず、短縮サマリだけを出す。プラグイン更新のたびに初回用の長文が毎回流れる問題を解消
