# ベストプラクティス集

開発で得た知見を自動蓄積するファイル。全プロジェクトのClaudeが参照・追記する。
案件をこなすほどClaude Codeが賢くなる仕組みの中核。

## 記録ルール

- 新しいライブラリ・パターン・ツール・APIの使い方を発見したら自動追記される
- 上手くいかなかったアプローチ（アンチパターン）は「注意点・落とし穴」に記録
- 同じパターンが再発したら **新規エントリではなく既存エントリの信頼度を上げる**
- 末尾の `(信頼度: N)` は省略不可

## 信頼度スコア（重要）

| スコア | 意味 | 扱い |
|-------|------|------|
| 1 | 1回観測 | 参考情報（他案件で再発するか様子見） |
| 2 ⚠️ 再発 | 2回観測 | 同じパターンが再発 → CLAUDE.md / rules 化を検討 |
| 3 🔴 強い知見 | 3回以上 | CLAUDE.md / rules / Hook 化を強く推奨 |

月1回の weekly-checklist 「項目5 信頼度スコアの昇格チェック」で棚卸しする。

## 記録フォーマット

```markdown
- [YYYY-MM-DD] 項目名: 説明 (信頼度: 1)
```
