# UI禁止パターン チェックリスト

AI生成UIの「AIっぽさ」を排除するための禁止パターン集。
フロントエンド実装時（shadcn/ui + Tailwind CSS環境）に参照する。

出典: melta-ui (tsubotax) + 実開発での知見

## 必須（実装時に毎回確認）

### カラー
- [ ] `text-black` 禁止 → `text-slate-900` を使う
- [ ] `bg-gray-300`以上の暗い背景 禁止 → `bg-gray-50`〜`bg-gray-200`
- [ ] `text-gray-400`を本文に使用 禁止 → コントラスト不足。`text-slate-600`以上
- [ ] `bg-blue-*`, `bg-indigo-*` のハードコード 禁止 → CSS変数 or テーマカラーを使う
- [ ] 色だけで情報を伝達 禁止 → アイコン/テキストを必ず併用

### シャドウ・装飾（最も効果大）
- [ ] `shadow-lg` / `shadow-2xl` 禁止 → `shadow-sm`〜`shadow-md` で十分
- [ ] カード上部/左部のカラーバー 禁止 → `border border-slate-200` の全周ボーダー
- [ ] 左端/上端のカラーストライプ 禁止 → 全周ボーダーで統一
- [ ] 紫グラデーション背景 禁止 → AIが好む典型パターン。ソリッドカラーに
- [ ] 過剰な`rounded-full` 禁止 → `rounded-lg`〜`rounded-xl` が適切

### スペーシング
- [ ] カード内の `p-0`〜`p-2` 禁止 → `p-4`〜`p-6` で余白を確保
- [ ] セクション間の `gap-0`〜`gap-2` 禁止 → `gap-6` 以上
- [ ] ページコンテンツの `m-0` 禁止 → `px-6 py-8` 以上
- [ ] サイドバーの暗い背景 禁止 → `bg-white` + ボーダー（shadcn/ui準拠）

### タイポグラフィ
- [ ] 本文の `text-xs` 禁止 → `text-sm`（14px）以上
- [ ] `font-light`（300）禁止 → `font-normal`（400）以上
- [ ] `tracking-tight` 禁止 → `tracking-normal` 以上

### 絵文字・装飾テキスト
- [ ] 見出しやラベルへの絵文字多用 禁止 → Lucide等のアイコンを使う
- [ ] 「🚀」「✨」「🎉」等のAI典型絵文字 禁止 → 必要な場合のみ、控えめに

## フォーム（入力画面作成時に確認）
- [ ] ブラウザネイティブの `type="date"` / `type="time"` 禁止 → デザイン・操作性がOS/ブラウザ依存で統一感がない。以下のカスタムコンポーネントを使う：
  - **日付選択（カレンダー）**: shadcn Calendar+Popover ベースのカスタムDatePicker
    - 土曜=青（`text-blue-500`）、日曜=赤（`text-red-500`）、祝日=赤
    - 角丸の選択状態、前月/翌月の日付はグレーアウト
    - デフォルトのshadcn Calendarそのままは使わない（曜日色なし・デザインが地味すぎる）
  - **生年月日・年月指定**: カレンダーポップアップを使わない → 年・月・日を**3つの独立したドロップダウン（Select）**で並べる
    - 年: `<Select>` 西暦の降順（現在年〜1920年程度）
    - 月: `<Select>` 1〜12月
    - 日: `<Select>` 1〜28/29/30/31（月に応じて動的変更）
    - 生年月日でカレンダーUIを出すと何十年もスクロールする必要があり使いにくい
  - **時刻**: 時・分のSelectドロップダウン横並び（5分刻み）
  - これらが存在するプロジェクトでは**常にこちらを使う**。新規プロジェクトでも同じパターンで作成する
- [ ] プレースホルダーのみでラベル省略 禁止 → `<label>` を必ず使用
- [ ] ラベルの横配置 禁止 → ラベルは入力欄の上に配置
- [ ] エラーメッセージの自動非表示 禁止 → ユーザーが修正するまで表示
- [ ] 色のみによるエラー状態 禁止 → ボーダー + アイコン + テキストを併用
- [ ] エラー表示が入力欄から離れている 禁止 → フィールド直下に表示

## アラート・通知（確認・成功・エラー表示時に確認）
- [ ] デフォルトのtoast（画面上部/下部から出る黒背景バー）禁止 → 画面中央にポップアップするデザインされたモーダルアラートを使う
  - **確認系**: shadcn `<AlertDialog>` — 中央表示、半透明オーバーレイ、明確なアクションボタン
  - **成功/エラー通知**: shadcn `<Dialog>` でカスタムアラート — アイコン（CheckCircle/XCircle）+ メッセージ + 閉じるボタン
  - **軽い通知（保存完了等）**: sonner toast は許可するが、スタイルをカスタマイズして使う（黒背景そのままは禁止）
- [ ] `window.confirm` / `window.alert` / `window.prompt` 禁止 → ドメイン名が表示されるため、必ずカスタムダイアログを使う

## モーダル・ダイアログ（モーダル実装時に確認）
- [ ] フォーカストラップなし 禁止 → Tab/Shift+Tabがモーダル内を循環
- [ ] Escキーで閉じられない 禁止 → Escで閉じる
- [ ] オーバーレイなし 禁止 → 半透明オーバーレイを使用
- [ ] `role="dialog"` 省略 禁止 → 必ず付与

## アニメーション
- [ ] `duration-500` 以上 禁止 → `duration-150`〜`duration-300`
- [ ] 常時ループアニメーション 禁止 → 状態変化時のフィードバックのみ
- [ ] `prefers-reduced-motion` 無視 禁止 → メディアクエリで対応

## アクセシビリティ
- [ ] `outline: none`（ring なし）禁止 → `focus:ring-2 focus:ring-primary/50`
- [ ] アイコンボタンの `aria-label` 省略 禁止 → `aria-label="閉じる"` 等を付与
- [ ] 44px 未満のタップ領域 禁止 → パディングで確保

## やりがちなAI生成パターン（要注意）
- カード上部に太いカラーバーを付ける → **最頻出。全周ボーダーに変更**
- やたらとグラデーションを使う → ソリッドカラーに
- ボタンに強い影をつける → shadow-sm以下に
- 全てのセクションにアイコンを付ける → 必要な箇所だけに
- ヘッダーに大きなグラデーション背景 → シンプルな背景色に
- カードごとに違う色のアクセント → 統一したテーマカラーに
